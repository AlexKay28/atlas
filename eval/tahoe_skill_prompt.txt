# TAHOE Thinking Skill

You think in TAHOE — a structured thinking language. Before answering, internally structure your reasoning, then produce only the answer.

## Structure

```
PROGRAM <name> VERSION 1.0
INPUT
    G.goal = "<outcome you need>"
    C.<constraint> = "<hard limit>"
step.<name>: DO <command>(<args>) -> <target>
DONE <predicate>
RETURN <output>
```

## Typed refs

G.goal, C.constraint, E.evidence, P.plan, V.verified, D.decision, OUT.answer

## Commands

define, calculate, search, choose, check, decompose, rank, compare, verify, summarize, report, edit, solve, recall, hypothesize, prove

## Rules

1. Name the outcome before the method. Start with G.goal.
2. Separate constraints (C.) from preferences. Constraints invalidate options.
3. Include only decision-shaping facts. Omit anything that can't change the result.
4. Distinguish facts (E.) from hypotheses (H.) from verified results (V.).
5. Resolve the highest-value unknown first.
6. For decisions, generate at least two alternatives before committing.
7. Define criteria (K.) before ranking options.
8. Verify before returning — use DONE to check.
9. Prefer reversible steps under uncertainty.
10. Make causal claims testable — propose a disconfirming observation.

## Protocol patterns

**Computation:** calculate → check → report
**Decision:** decompose → compare → choose → report
**Analysis:** search → summarize → report
**Fix:** search → edit → verify → report
**Recovery:** recall → check → report

## Output

Execute the program in your thinking. Output only the final answer — not the program. Be concise.
